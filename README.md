## 先搞清楚你要的是哪一種 VPS

用途決定線路，線路決定價格。同一個價位帶，選錯線路的後果比選錯規格嚴重得多。

**建站、跑服務**：看線路穩定性與延遲。CN2 GIA 或 AS9929 是目前的常見選擇。LightLayer 對應的是洛杉磯 Standard 與 Premium 兩檔，Premium 明確走 CN2 GIA（電信）與 CMIN2（移動）。

**跨境電商、TikTok 運營**：IP 品質是核心，需要原生住宅 IP，普通資料中心 IP 容易被風控。這條需求 LightLayer 接不住。它賣的是線路與算力，方案裡沒有標示住宅 IP 的產品線。要真的住宅 IP，市場上的選擇是麗薩主機這類專做雙 ISP 家寬住宅 IP 的商家，美國 9929 雙 ISP 住宅 IP 月付 68 元人民幣起，年付特價 199 元人民幣起。

**串流解鎖**：需要對應地區的原生 IP。第三方對 LightLayer 機器的解鎖表現評價不錯，但機房 IP 與住宅 IP 是兩回事，解鎖成功率和帳號安全性不能混為一談。

**科學上網**：優化線路加乾淨 IP 即可，不必追住宅級別。這一類用洛杉磯 Premium 年付最直接。

## 線路代號到底在說什麼

CN2 GIA 是中國電信的優質骨幹線路，擁塞少、成本高，晚高峰的差別最明顯。CMIN2 是中國移動的精品網，同屬高品質通道。AS9929 是中國聯通的精品網，常被拿來跟 CN2 GIA 並列討論。AS4837 也是聯通，但屬於相對便宜的國際線路，價格低一截，高峰期表現看運氣。普通國際 BGP 最便宜，晚高峰卡到無法使用是常態。

LightLayer 的分級只有三檔，Premium 公開寫明是 CN2 GIA 加 CMIN2，覆蓋電信與移動兩家。Standard 和 Global 沒有公開具體路由，第三方也沒有拆解過。這一塊的資訊是缺的，如果你對線路有明確要求，直接從 Premium 起步，別在 Standard 上賭。

還有一個常被忽略的常識：很多商家賣的「香港 IP」其實只是中轉，機器在香港、出口繞一圈，解鎖能力參差不齊。買之前問清楚 IP 歸屬和實際路由，比看機房城市有用。
